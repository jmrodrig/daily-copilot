# Interface mockups

Dark-mode design mockups, exported from the "Co-Pilot Interface Mockups" canvas.

**Start with `screenshots/`**: rendered views of the mockups, the quickest way to see the intended look.

Desktop web app (1440 wide):
- `4-desktop-today` — Today: timeline of scheduled blocks, Coming up list, co-pilot chat pane with model and access picker
- `5-desktop-all-tasks` — All tasks table
- `6-desktop-gantt-with-linked-design-tasks` — per-project Gantt, shop floor tasks with linked design tasks (amber) and float
- `7-desktop-task-page` — a task page with metadata header and subtasks
- `8-desktop-meeting-page` — a meeting page with the prep brief
- `9-desktop-notes-graph` — notes graph
- `10-desktop-note-page` — a note in Notes-in
- `11-desktop-people` — People
- `12-desktop-forwarded-emails` — forwarded emails archive
- `13-desktop-new-page-templates` — template gallery

Android (390x844): `1-android-capture`, `2-android-morning-list`, `3-android-evening-checkin`.

Source files (exact colours, spacing, type, copy, interaction states):
- `Main.dc.html` — desktop app
- `Capture.dc.html`, `Morning.dc.html`, `Evening.dc.html` — Android screens
- `canvas.json` — artboard layout index (sizes and positions only)

These are static mockups with SAMPLE data. "Project A" and "Project B" stand in for the real projects C7801 and R5301; P5002 is shown by its real code. The HTML files need a design-component runtime that is not included, so read them as markup rather than opening them in a browser. Reproduce the design; do not copy the markup structure.
